# PDF/文档签章排版工具

在线使用：https://yinxi800.github.io/

## 合同/PDF快速签章及扫描版生成功能

解决人工打印合同、盖章签名、重新扫描上传的低效问题。文件全程在浏览器本地处理，不上传服务器。

### 功能特性

- **文件上传**：支持 PDF、扫描版 PDF、图片型 PDF、JPG/PNG 扫描图片
- **页面识别**：自动读取页面尺寸、方向、分辨率、DPI、色彩模式
- **签章定位**：人工拖拽 / 缩放 / 旋转签章，支持多页多签章
- **尺寸匹配**：印章按物理尺寸（mm）管理，自动计算显示大小
- **印章质感**：5 档预设（清晰原印 / 均匀实印 / 自然盖印 / 轻压浅印 / 缺墨旧印），可微调墨色与边缘
- **扫描效果**：三档预设（轻微 / 中等 / 明显），可微调模糊 / 噪声 / 亮度 / 对比度
- **纸边效果**：开启后以翻拍方式合成浅色底面 + 柔和投影 + 细边框，纸张边缘清晰
- **导出**：生成签署扫描版 PDF，预览与导出结果保持一致
- **语言**：中文 / English

### 浏览器支持

Chrome / Edge 90+、Safari 15+（构建产物已内置所需 polyfill）
